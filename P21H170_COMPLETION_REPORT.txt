【编译错误修复】

1️⃣  驱动加载错误
    问题: drivers/Kconfig:228: can't open file "drivers/kernelsu/Kconfig"
    原因: 符号链接指向不存在的目录
    修复: 删除无效的 KernelSU 配置引用
    状态: ✓ 已解决

2️⃣  内存安全问题
    问题: tools/lib/subcmd/subcmd-util.h - use-after-free
    原因: realloc() 失败后继续使用原指针
    修复: 简化内存分配逻辑
    状态: ✓ 已解决

3️⃣  函数签名不匹配
    问题: include/linux/sprd_iommu.h - void 函数有 return 语句
    原因: 函数原型定义错误
    修复: 删除无效 return，添加函数存根
    状态: ✓ 已解决

4️⃣  链接器错误
    问题: scripts/dtc/Makefile - undefined reference to yaml_*
    原因: YAML 支持不可用
    修复: 禁用 YAML 支持编译
    状态: ✓ 已解决

【技术架构】

设备树加载流程:
┌─────────────────────────────────────────────────────────┐
│ 1. Bootloader 加载基础 DTB (ums512.dtb)                  │
│ 2. Bootloader 加载设备 DTBO (ums512-1h170.dtbo)          │
│ 3. 内核启动时合并两个设备树                               │
│ 4. 驱动根据 compatible 匹配对应代码                       │
│ 5. 根据 sc-id 应用硬件特定参数                            │
└─────────────────────────────────────────────────────────┘

兼容性策略:
  • Compatible: "sprd,ums512-1h10" (保持与 P21H180 驱动兼容)
  • SC-ID: "ums512 1h170 1000" (用于硬件特定配置)
  • Model: "Unisoc UMS512 1H170 board" (用户识别)
  • 结果: 驱动代码无需修改，仅通过设备树参数调整
